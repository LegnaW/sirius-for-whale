# core.engage 首版

显式启动的一次性交战。按 UUID 指定目标，或在 4–16 格搜索范围内按已知敌对类型的威胁排序后锁定一只。每轮检查血量与附近威胁；低血、被围、丢失、无法接近或超时即停。移动与战斗共用一个租约，Baritone 禁止破坏和放置；先停移动再近战。不自动恢复或切换目标，受击唤醒仍运行。

验证项包括移动目标、停稳后攻击、低血、被围和追击期间取消。只改 Whale，复用现有桥能力。真机验收在生存测试区由 DSH 执行。
