# 背包搬运与容器存取

新增两个 once 内置脚本，复用当前打开的界面及 bridge 1.10 的容器转移原语。背包按玩家槽号映射，箱子按物品 ID 和数量先存后取。读改期间持有 inventory 租约，使用客户端回读核对，未知时停止。

验收覆盖槽位映射、跨槽存取、部分结果与旧桥降级，随后由 DSH 真机复验。

## 验证记录

- 容器兼容性修正按当前菜单暴露的容器槽与玩家存储槽判断，转移仍由 bridge 校验槽位规则。回归用自定义界面类名模拟模组容器。

- `npm test` 273 项通过。真实 Worker 和模拟桥验证菜单槽映射、跨槽存取、部分结果、读回期间关窗、无窗口、旧桥降级及库存租约。
- `git diff --check` 通过。bridge 源码与游戏 jar 无需更新。
- 真机待验。两次 RPC 之间由玩家更换菜单可能产生竞态，测试期间保持当前菜单。遇到读回失败或结果未知，重新检查实际槽位后再决定剩余操作。
